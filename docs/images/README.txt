Carpeta para los pósters de las películas. `poster-no-disponible.svg` es el recurso local que se muestra cuando la API devuelve una ruta de póster que no está disponible.

Añade las siguientes imágenes con exactamente estos nombres:
- poster-diario-de-una-pasion.jpg
- poster-jurassic-park.jpg
- poster-cielo-rojo.jpg
- poster-el-viaje-de-chihiro.jpg

Los estudiantes pueden añadir las imágenes localmente en esta carpeta. Para que se muestren sin usar el póster neutral, agrega el archivo aquí y registra su ruta en `localPosterPaths` en `js/app.js`.
